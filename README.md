# LJT-Homepage

Personal academic homepage for **Junteng Liu**, forked from [Academic Pages](https://github.com/academicpages/academicpages.github.io) and renamed as requested.

The site content is based only on the profile information available in memory and includes:

- Personal details and contact links
- Academic background, honors, and research experience
- Skills and research expertise
- Publications on both the home/About section and the dedicated [Publications page](_pages/publications.html)
- A structured [CV page](_pages/cv.md)

## Repository structure

- `_pages/about.md` — home/About page with the complete profile and publication list
- `_pages/publications.html` — publication index
- `_publications/` — publication records used by the Academic Pages collection
- `_pages/cv.md` — curriculum vitae page
- `_config.yml` — site, author, URL, and collection configuration
- `_data/navigation.yml` — main navigation

## Local preview

This repository uses the standard Academic Pages/Jekyll setup. See the upstream template documentation in the repository history or [academicpages.github.io](https://github.com/academicpages/academicpages.github.io) for Ruby, Bundler, and local preview instructions.
